# StayLuxe

A premium luxury hotel booking platform built with Pure PHP, featuring elegant UI design, smart room booking, secure payments, and a seamless modern hospitality experience.

**📌 About the Project**

StayLuxe is a modern hotel booking and management platform designed to provide users with a smooth, elegant, and luxurious booking experience. The platform combines minimal aesthetics with high-performance backend functionality to deliver a premium hospitality solution.

From browsing luxury rooms to instant booking confirmations, StayLuxe focuses on simplicity, speed, and sophistication.

**✨ Features**

🏨 Luxury Room Booking System
📅 Real-Time Room Availability
💳 Secure Payment Integration
⚡ Instant Booking Confirmation
🛏️ Personalized Room Preferences
🧹 Housekeeping Scheduling
🕑 Late Checkout Requests
📧 Email & SMS Notifications
🌌 Premium Glassmorphism UI
📱 Fully Responsive Design
